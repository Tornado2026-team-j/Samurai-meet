# 機能仕様：プロフィール

最終更新: 2026-08-26

## 1. 対象

ユーザーが交流前に相手を判断できるよう、名前、国籍、アイコン、本人確認状態、いいね数、自己紹介、交流キーワードを管理します。

対応要件：FR-004、C-001、C-002、C-003、C-005

## 2. 入力項目

| 項目 | 必須 | 公開範囲 | 実装 |
| --- | --- | --- | --- |
| 名前 | Yes | マッチ候補・チャット相手 | TSX フォーム + Go 検証 |
| 国籍 | Yes | マッチ候補・チャット相手 | ISO コードを TypeScript / DB で管理 |
| アイコン | No | マッチ候補・チャット相手 | TypeScript で選択、Go で保存 |
| 本人確認状態 | 自動 | `verified` 等のバッジ | Go の審査状態を表示 |
| いいね数 | 自動 | 集計値 | Go / SQL で更新 |
| モンスター | 要確認 | 要確認 | 型、意味、公開範囲を決定 |
| 自己紹介 | No | マッチ候補・チャット相手 | Go APIで文字数検証済み。編集UIは未接続 |
| 交流キーワード | No | 検索・プロフィール | 正規化して検索に利用 |

## 3. 画面

| 画面 | ファイル案 | 内容 |
| --- | --- | --- |
| プロフィール表示 | `frontend/app/(tabs)/profile.tsx` | 自分のプロフィール、本人確認、評価を表示 |
| プロフィール編集 | `frontend/components/ProfileForm.tsx` | 項目編集、入力エラー、保存 |
| 相手プロフィール | `frontend/components/MatchCard.tsx` または追加画面 | 公開項目だけを表示 |

## 4. API / DB

- `GET /api/v1/me`（実装済み。Access Token必須）
- `PATCH /api/v1/me/profile`（実装済み。Access Token必須）
- `POST /photos`（アイコン登録時）
- `DELETE /photos/{id}`
- `profiles.user_id` を主キーとする。
- `likes_count`、`identity_status` はクライアントから更新不可。

### プロフィール更新の契約

`PATCH /api/v1/me/profile` は次のJSONを受け付けます。指定しなかった項目は既存値を維持します。

```json
{
  "name": "表示名",
  "nationality_code": "JP",
  "bio": "あとから変更できる自己紹介"
}
```

- `name` は必須の完成プロフィールで最大64 Unicode code points。次回以降のPasskey登録表示名にも使う。
- `nationality_code` は大文字2文字のISO 3166-1 alpha-2コード。
- `bio` は任意で最大1000 Unicode code points。改行・タブは許可する。
- 空の名前・不正な国コード・制御文字・上限超過は `400 invalid_profile`。
- 自分のプロフィールだけを更新でき、`identity_status` と `likes_count` はAPI入力に含めても無視される。
- アイコン参照、本人確認、交流キーワードの更新APIはこの変更の対象外。

成功時は `{ "data": { ...profile } }` を返します。`GET /api/v1/me` は同じプロフィール形式を返し、`completed` は名前と国コードが揃っている場合にtrueです。

## 5. 業務ルール

- 名前は表示名として扱い、戸籍上の氏名を必須にしない。
- 国籍は自由入力ではなく、国コードの選択式を基本とする。
- アイコン削除後はデフォルトアバターを表示する。
- 他ユーザーへは本人確認書類や審査理由を表示しない。
- 退会ユーザーのプロフィールは削除済み表示または匿名化する。
- プロフィール公開に必要な必須項目が未入力の場合、募集カードを公開できない。
- 自己紹介は保存後、アプリ再起動後もAPIから取得できる。

## 6. 受け入れ条件

- 名前・国籍を入力して保存できる。
- 保存後、アプリ再起動後も内容が表示される。
- 不正な文字数・国コード・制御文字を API が拒否する。
- 他ユーザーのプロフィールを編集できない。
- いいね数と本人確認状態を UI から改ざんできない。

## 7. 要確認

- 「モンスター」が示す概念と保存形式。
- 名前に本名を要求するか、ニックネームを許可するか。
- 自己紹介の対応言語、禁止語、文字数。
- 国籍を複数選択できるか。
